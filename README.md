# 🎬 Movie Genre Classification

**Machine Learning | Natural Language Processing | Python**

A machine learning project that predicts movie genres based on their plot descriptions using Natural Language Processing techniques.

---

## 📌 Overview

Movies belong to different genres such as Action, Comedy, Drama, Horror, Romance, and Thriller. Identifying a movie's genre based on its storyline is an interesting application of Machine Learning and Natural Language Processing.

**Movie Genre Classification** is a Python-based project that analyzes textual movie descriptions and predicts their corresponding genres using a trained machine learning model.

The project uses NLP techniques to process text and convert it into numerical features that can be understood by a machine learning algorithm. The trained model then uses these features to classify movie descriptions into their respective genres.

## 🎯 Project Objectives

- Understand and implement Natural Language Processing techniques.
- Process and analyze movie plot descriptions.
- Convert textual information into numerical features.
- Train a machine learning model for genre classification.
- Predict movie genres from new descriptions.
- Gain practical experience in developing an end-to-end ML project.

## ⚙️ Technologies Used

- **Python** – Core programming language.
- **Pandas** – Dataset handling and manipulation.
- **NumPy** – Numerical operations.
- **Scikit-learn** – Machine learning and model training.
- **TF-IDF Vectorization** – Text feature extraction.
- **Joblib** – Saving and loading trained models.

## 🔄 Project Workflow

**1. Data Collection**

A movie dataset containing textual descriptions and their corresponding genre labels is used for training and testing.

**2. Data Preprocessing**

The textual data is cleaned and prepared for model training by handling missing values and preparing descriptions for feature extraction.

**3. Feature Extraction**

TF-IDF (Term Frequency–Inverse Document Frequency) converts movie descriptions into numerical feature representations.

**4. Model Training**

The processed data is used to train a machine learning classification model that learns patterns between movie descriptions and their genres.

**5. Model Evaluation**

The model is tested using unseen data to evaluate its classification performance.

**6. Genre Prediction**

The trained model accepts a new movie description and predicts its most likely genre.

## 📂 Project Structure

The project is organized into the following main components:

- **dataset/** – Contains the movie dataset.
- **models/** – Stores the trained machine learning model and TF-IDF vectorizer.
- **train.py** – Handles data preprocessing and model training.
- **predict.py** – Used to predict genres from new movie descriptions.
- **requirements.txt** – Contains the required Python libraries.
- **README.md** – Project documentation.

## 🚀 Getting Started

To run this project on your local machine:

1. Clone or download this repository.
2. Open the project folder in VS Code or any Python-supported editor.
3. Create and activate a Python virtual environment.
4. Install the required libraries using the requirements file.
